以下是一个面向理工科学生的交互式教学网页大纲，主题为“音名 vs. 唱名：固定身份与可移动称呼”。
大纲强调直观的动态映射、可调节参数以及背后的频率/数学逻辑，让理工科学生既能直观感受，又能理解其数学本质。

一、页面总体目标
清晰对比：音名（C, D, E…）是绝对音高标识，唱名（Do, Re, Mi…）是相对音级称呼。

交互探索：通过点击钢琴键或改变“调性”滑块，实时看到音名与唱名的对应关系变化。

理工科深度附加：展示每个音的频率（Hz），以及不同调式下的频率比值关系（12平均律）。

二、页面布局（三段式）
1. 顶部：概念卡牌（图文并茂）
左侧卡片：音名 – 固定，像身份证号（C4 = 261.63 Hz）。

右侧卡片：唱名 – 可移动，像班级职务（Do 的位置随调性改变）。

中间动态公式：展示当前调性下的映射关系，例如：
G 大调：Do → G, Re → A, Mi → B, Fa → C …

2. 中部：交互核心区（钢琴 + 映射表）
可点击的钢琴键盘（至少一个八度，C4 ~ B4）。

鼠标悬停/点击某一键 → 显示该键的音名、当前调性下的唱名、以及频率值。

高亮当前调性的“Do”音所在的键。

音名–唱名动态映射表（表格形式）
行：7个唱名（Do, Re, Mi, Fa, Sol, La, Si）
列：当前调性对应的音名字母（例如 C大调：C, D, E…；G大调：G, A, B…）
支持高亮显示偏差（比如升降号用红色标记）。

3. 底部：控制面板与实验工具
调性选择器：下拉框或滑块，支持 C, D, G, F 等常用大调。
变化时 → 钢琴键上的唱名标签实时刷新，映射表重绘。

“固定Do参照”开关（理工科特色）：

关闭（默认）：Do 随调性移动。

开启：强制将 Do 对应到 C 音（即类似固定唱名法），此时可对比两种唱名体系的差异。

实时频率显示条形图：显示当前八度内各音的频率（对数坐标更符合听觉），点击某音时显示其与主音（Do）的频率比值（整数比近似）。

三、交互流程与学习路径（引导式）
初始加载：默认 C 大调，音名 = 唱名，钢琴键上同时显示 C / Do 等。

学生点击某个键：弹窗或侧边栏提示：“音名永远是这个C，但Do现在在C上；若换成G大调，Do会跑到G键上”。

学生切换调性为 G 大调：

钢琴键上原来的 C 标签从“Do”变为“Fa”（因为 G 大调中，C 是 Fa）。

映射表更新，G 键上出现“Do”。

图表显示频率比值：G 与 C 的频率比 = 3:2（纯五度）。

点击“固定 Do 参照”：

钢琴键上的唱名不再随调性变化（Do 永远在 C 上），此时可对比“移动Do”与“固定Do”两种唱名法的应用场景。
